# 4Dental App Website

Plain product chooser for **4Dental Clinic** and **4Dental Lab**. No header or footer — brand, two destinations, done.

Opens:
- [4dental.clinic](https://4dental.clinic)
- [4dental-lab.com](https://4dental-lab.com)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Optional env

| Variable | Default |
|----------|---------|
| `NEXT_PUBLIC_SITE_DOMAIN` | `4dental.app` |
| `NEXT_PUBLIC_CLINIC_URL` | `https://4dental.clinic` |
| `NEXT_PUBLIC_LAB_URL` | `https://4dental-lab.com` |

## Brand

Matches the sibling sites: Manrope + Sora, ambient grid/aurora, clinic green `#0d9f6e`, lab purple `#6b4eaa`.
